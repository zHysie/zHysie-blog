# 品牌标准

这个目录保存已经确定、但不一定已经应用到网站中的品牌设计标准。它属于 `system/globals/`，是项目全局设计规范的一部分。

| 范围 | 文档 | 状态 |
| --- | --- | --- |
| Logo 品牌色 | [`标志与品牌色标准.md`](./标志与品牌色标准.md) | 蓝色与粉色已确定，尚未应用 |
| 英文排版 | [`英文排版标准.md`](./英文排版标准.md) | 目标已确定，尚未应用 |
| 中文排版 | 尚未定义 | 等待用户确认 |

## 使用原则

- 这里的文档用于规定网站未来应采用的品牌设计方案。
- 上一级全局规范用于说明网站当前已经实现的设计，并链接到对应的目标标准。
- 应用这些标准时，必须先转换为设计变量，不能在组件或页面中直接写字体名称。
- 第三方字体文件不应放在这个规范目录中。
