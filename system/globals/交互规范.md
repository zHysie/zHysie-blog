# 交互规范

本规范适用于按钮、链接、标签页和输入框等交互元素。

## 交互状态

所有适用状态都必须定义：

- **悬浮：** 使用 `--primary-hover` 或 `--secondary-hover` 产生轻微抬升或颜色变化。
- **按下：** 使用 `--primary-active` 产生轻微缩放或更深的色调。
- **键盘焦点：** 使用 `outline: 2px solid var(--ring); outline-offset: 2px;`，禁止移除焦点样式。
- **禁用：** 降低透明度，设置 `cursor: not-allowed`，并且不能获得焦点。
- **选中：** 标签页和切换控件使用填充的 `--primary` 背景以及 `--primary-foreground` 文字。

## 按钮

- 使用 `Button` 界面组件，其 `variant` 可选 `primary`、`secondary` 等类型。
- 主要按钮使用实心 `--primary`；次级按钮使用边框或 `--secondary`。
- 只有图标的按钮必须提供 `aria-label`。

## 链接

- 文章正文中的行内链接使用 `--primary`。在本项目的单色系统中，它接近前景文字色，同时需要下划线和 `text-underline-offset`。
- 导航链接必须提供清晰的悬浮状态，当前路由使用 `aria-current`。

## 动效

- 过渡时间保持在 150 到 250 毫秒，并使用缓出曲线。
- 所有非必要动效都必须遵守 `prefers-reduced-motion: reduce`。
- 元素进入视口的效果使用 `data-animate` 纯 CSS 滚动显示工具。

## 使用规则

- 每个交互元素都必须能通过键盘访问，并显示清晰的焦点环。
- 纯视觉行为优先使用 CSS，不能因此引入客户端 JavaScript。
