# 图像规范

## 图像组件

- 位图资源使用 Astro 的 `Image`、`Picture` 或项目中的 `Img` 封装组件。内容图片不能直接使用原始 `<img>`，以保证图像优化、尺寸设置和布局稳定性。
- 图标使用 `astro-icon`，图标来源为 Lucide（`lucide:*`）和 Simple Icons（`simple-icons:*`）。图标使用内联 SVG，通过 `currentColor` 继承颜色，并以 `rem` 设置尺寸。

## 基本要求

- **每张图片都必须提供有意义的 `alt`。** 装饰性图片使用 `alt=""` 并添加 `aria-hidden="true"`。`check:kpis` 会提示缺少 `alt` 的图片。
- 提供明确的 `width` 和 `height`，或设置宽高比，避免页面布局偏移。
- 优先使用 SVG 和 `woff2`；首屏以下的媒体资源采用延迟加载。
- 使用 `--radius-lg` 或 `--radius-xl` 设置图片圆角；图片不能超出容器宽度。

## OG 与社交分享图片

- OG 图片由 `src/lib/og.ts` 在 `/og/[...slug]` 路由动态生成，颜色来自 `site.config.ts`。对于图像生成，这是允许保存直接品牌颜色值的位置。
