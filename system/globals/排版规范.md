# 排版规范

排版变量定义在 `src/styles/tokens/typography.css`，并在 `global.css` 中映射到 Tailwind。

## 已确定的目标标准

英文品牌排版标准记录在 [`brand-standards/英文排版标准.md`](./brand-standards/英文排版标准.md)：

- 英文标题：`Anthropic Serif`，字重 500。
- 英文正文和界面文字：`Anthropic Sans`，字重 400。
- 中文排版：等待用户另行确认。

这个标准已经应用到网页，并使用项目内字体文件自行托管。

## 当前实现

| 变量 | 字体 | 用途 |
| --- | --- | --- |
| `--font-sans` | Anthropic Sans | 英文正文与界面文字 |
| `--font-heading` | Anthropic Serif | 英文标题 |
| `--font-typewriter` | 原神汉仪文黑 85W | 首页打字语句，独立于中英文全局字体 |
| `--font-mono` | JetBrains Mono Variable | 代码 |

当前字体通过 Fontsource **自行托管**，没有使用 CDN。经过尺寸校正的备用字体 `@font-face` 规则用于减少页面布局偏移（CLS）。

## 流式字号体系

字号通过 `clamp()` 在手机和桌面尺寸之间平滑变化：

`--text-xs` 12–14 · `--text-sm` 14–16 · `--text-base` 16–18 · `--text-lg` 18–20 ·
`--text-xl` 20–24 · `--text-2xl` 24–32 · `--text-3xl` 30–40 · `--text-4xl` 36–48 ·
`--text-5xl` 48–64。

标题变量 `--heading-h1` 到 `--heading-h6` 对应上述字号体系。

## 字重与阅读节奏

- 字重变量：`--font-weight-{light,normal,medium,semibold,bold,extrabold}`。
- 标题默认使用 `--font-weight-semibold` 和 `--leading-tight`。
- 正文使用 `--leading-normal`，长文章正文使用 `--leading-relaxed`。
- 超大标题可以使用较紧的 `--tracking-tight` 字间距，其他位置保持默认字间距。

## 使用规则

- 按照语义使用标题元素，每个页面只能有一个 `h1`，标题层级不能跳级。
- 文章正文宽度控制在约 65 到 72 个英文字符内，保证可读性。
- 优先使用现有字号变量，不要随意添加独立字号。
- 区块上方的小标签使用大写、`--text-xs`、较宽字间距，并使用 `--muted-foreground` 或 `--primary` 颜色变量。
- 首页打字语句只能使用 `--font-typewriter`。以后调整中文或英文字体时，不得修改、复用或覆盖该变量。
