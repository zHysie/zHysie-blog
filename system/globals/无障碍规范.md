# 无障碍规范

目标：符合 WCAG 2.1 AA 级标准。

## 页面结构

- 使用语义化区域：`header`、`nav`、`main`、`footer`、`article`、`aside`。
- 每个页面只能有一个 `h1`；标题顺序必须符合逻辑，不能跳过层级。
- 提供跳转到主要内容的链接（`.skip-link`）。

## 色彩与对比度

- 正文对比度不低于 4.5:1；大号文字和界面元素不低于 3:1。现有单色变量已经针对这些要求调整，新增任何前景色与背景色组合时仍需重新检查。
- 不能只依靠颜色传达含义，必须同时配合文字或图标。

## 键盘与焦点

- 所有交互元素都必须能够通过键盘访问和操作。
- 所有交互元素都必须显示清晰的焦点环（`:focus-visible` → `--ring`）。除非提供等效替代样式，否则禁止使用 `outline: none`。
- 菜单和弹窗需要正确管理焦点，关闭后将焦点恢复到触发元素。

## 名称与语义

- 只有图标的控件必须提供 `aria-label`。
- 图片必须提供 `alt`；装饰性图片使用空的 `alt`，并设置 `aria-hidden`。
- 当前导航项使用 `aria-current`；展开和折叠控件使用 `aria-expanded`。

## 动效

- 遵守 `prefers-reduced-motion: reduce`，关闭非必要动画和跑马灯自动滚动，并让内容正常换行显示。

## 验证

- `check:kpis` 会提示缺少 `alt` 的图片；新增组件还需要手动检查焦点顺序、颜色对比度和减少动态效果模式。
