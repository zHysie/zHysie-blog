# 组合模式

这些可复用的组合方案用于保持组件视觉统一。页面需要以下结构时，**应直接复用现有模式，不能临时创造新的变体**，这样可以避免界面逐渐偏离设计系统。所有示例只能使用设计变量，参见 `色彩规范.md`、`间距与布局规范.md`、`视觉效果规范.md`；同时需要支持减少动态效果模式，参见 `交互规范.md`。

## 图标徽章

使用带变量边框的方形或圆形容器包裹一个 `Icon`。`FeatureGrid`、`ServiceCard` 和 `ServiceLayout` 使用它作为视觉锚点。

```astro
<span class="icon-badge" aria-hidden="true">
  <Icon name="lucide:cloud" />
</span>
```

```css
.icon-badge {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  width: 2.75rem;
  height: 2.75rem;
  border-radius: var(--radius-full);
  background: var(--color-bg-secondary);
  border: 1px solid var(--color-border);
  color: var(--color-text-primary);
}
```

规则：图标徽章始终设置 `aria-hidden`，含义由旁边的标题表达；禁止使用彩色背景，层次只通过 `--color-bg-secondary` 和 `--color-border` 表现。

## 检查清单行

由 `lucide:check` 图标和文字标签组成，用于 `ServiceCard`、价格卡片以及 `FeatureTabs` 的要点列表。

```astro
<ul class="checklist">
  {items.map((item) => (
    <li><Icon name="lucide:check" /><span>{item}</span></li>
  ))}
</ul>
```

勾选图标使用 `--primary` 或 `--color-text-primary`，不能使用绿色，以保持单色系统。图标设置 `flex-shrink: 0`，尺寸约为 `1.0625rem`。

## 卡片骨架

组合现有的 `Card` 基础组件，不能重新制作一个带边框的盒子。媒体或徽章放入 `header` 插槽，正文区域放置内容，需要抬升效果时使用 `hover`。在纵向弹性布局中，通过 `margin-top: auto` 将行动按钮对齐到底部。

```astro
<Card hover class="my-card">
  <Fragment slot="header"><!-- 媒体或图标徽章 --></Fragment>
  <div class="my-card__body"><!-- 标题、正文、清单和行动按钮 --></div>
</Card>
```

`BlogCard` 和 `ServiceCard` 使用这种结构。圆角、边框和阴影由 `Card` 基础组件提供，禁止为单个卡片覆盖这些样式。

## 反色行动号召区

页面末尾的行动号召区域通过 `--surface-invert*` 自动反转明暗，使它在浅色和暗色模式中都表现为清晰、独立的区块。内容宽度受限，可以包含引导标签、实心主要按钮和描边次级按钮。

```astro
<CTA
  eyebrow="开始使用"
  title="准备好搭建你的网站了吗？"
  content="查看服务或阅读文档。"
  primaryText="查看服务" primaryHref="/services"
  secondaryText="阅读文档" secondaryHref="/docs"
/>
```

主要变量：`--surface-invert`（背景）、`--surface-invert-foreground`（文字）、`--surface-invert-border`（边框）。内部内容最大宽度为 `60rem` 并居中；纹理层设置 `aria-hidden`。主要按钮使用反色背景上的实心前景色，次级按钮使用描边样式。不要把该区块扩展为占满整个视口宽度。

## 胶囊与筛选标签

使用全圆角标签表示博客分类筛选和价格范围等辅助信息。激活状态反转为主要色调。

```css
.chip {
  border-radius: var(--radius-full);
  border: 1px solid var(--color-border);
  background: var(--color-bg-secondary);
  padding: 0.3rem 0.75rem;
  font-size: 0.8125rem;
}

.chip[aria-current="true"] {
  background: var(--primary);
  color: var(--primary-foreground);
}
```

## 单色封面

博客封面根据 `slug` 稳定生成，因此不需要单独的素材处理流程。实现位置为 `blog/BlogImageSVG.astro`。

- 对 `slug` 计算哈希，作为抽象图案的种子。
- 只能使用设计变量，例如 `var(--color-text-primary)`、`var(--color-bg-secondary)` 和 `currentColor`。禁止写内联 hex，也禁止使用带色相的渐变。
- SVG 内部不放文字，标题由卡片或文章页面单独渲染。

## 悬浮箭头提示

用于跳转的文字链接在末尾添加 `&rarr;` 箭头，悬浮时轻微向右移动。视觉隐藏文字补充目标名称，确保链接名称完整且符合无障碍要求。

```astro
<a class="arrow-link" href={href}>
  了解更多
  <span class="sr-only">：{title}</span>
  <span class="arrow-link__arrow" aria-hidden="true">&rarr;</span>
</a>
```

```css
.arrow-link__arrow { transition: transform 0.2s ease; }
:global(.card:hover) .arrow-link__arrow { transform: translateX(3px); }

@media (prefers-reduced-motion: reduce) {
  .arrow-link__arrow { transition: none; }
}
```

## 区块标题组

由居中的引导标签、标题和简介组成，并限制内容宽度。用于区块网格上方，保持统一的垂直节奏。使用 `global.css` 中的 `section-head` 类。

```astro
<header class="section-head">
  <p class="section-head__eyebrow">为什么选择这套技术</p>
  <h2 class="section-head__title">为性能和扩展能力而构建</h2>
  <p class="section-head__lead">快速发布网站所需的一切。</p>
</header>
```

设置 `max-width: 44rem`、`margin: 0 auto` 和 `text-align: center`。引导标签使用大写和较宽字间距，简介使用 `--muted-foreground`。

## 动效与焦点

- 每个过渡和动画都必须通过 `@media (prefers-reduced-motion: reduce)` 提供关闭方案，参见 `交互规范.md`。
- 禁止移除焦点环。基础组件已经提供 `focus-visible` 样式，自定义交互结构必须使用 `--ring` 添加等效焦点环。
- 纹理、光晕和网格等装饰图层必须设置 `aria-hidden` 和 `pointer-events: none`。
