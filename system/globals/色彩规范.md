# 色彩规范

这是项目颜色的唯一标准来源。颜色变量定义在 `src/styles/tokens/colors.css`，并通过 `src/styles/global.css` 中的 `@theme` 区块提供给 Tailwind。**禁止直接写颜色值**，包括 `#hex` 和 `bg-blue-500`，始终使用语义颜色变量。

## 色彩系统

- **颜色模型：** OKLCH（`oklch(L C H)`），用于获得更均匀的视觉明度。
- **基础色板：** 暖中性色。浅色画布使用更接近白色的暖中性色 `rgb(247, 246, 242)`，深色模式的浅色文字保留原纸张色 `rgb(240, 238, 230)`，主要墨色为柔和近黑色 `rgb(20, 20, 19)`。它们在 OKLCH 中只带极低的色度，让界面安静但不过度偏黄，也不显得像冷灰色。
- **暗黑模式：** 使用类名方案，在 `<html>` 上添加 `.dark`。每个语义变量都有浅色和暗色取值，组件只能引用变量，不能直接写某种模式的颜色。

## 已确定的 Logo 品牌色

Logo 的精确颜色记录在 [`brand-standards/标志与品牌色标准.md`](./brand-standards/标志与品牌色标准.md)：

| 名称    | HEX       | OKLCH                         |
| ------- | --------- | ----------------------------- |
| Logo 蓝 | `#64A5D8` | `oklch(0.6988 0.1006 243.60)` |
| Logo 粉 | `#E0A5B0` | `oklch(0.7803 0.0710 6.47)`   |

这两种颜色已映射为 `--brand-logo-blue` 和 `--brand-logo-pink`。除 Logo 外，只用于首页文章/日常的轻量强调和导航文字的悬浮装饰线，不作为按钮、状态提示或大面积背景色。

## 语义颜色变量

| 变量                                                                           | 用途                                                          |
| ------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| `--background` / `--foreground`                                                | 页面背景 / 主要文字                                           |
| `--card` / `--card-foreground`                                                 | 卡片和面板等浮层表面                                          |
| `--popover` / `--popover-foreground`                                           | 弹出层和菜单                                                  |
| `--primary` / `--primary-foreground`                                           | 主要操作和重点内容（近黑色 ↔ 近白色）                         |
| `--secondary` / `--secondary-foreground`                                       | 次级表面和次级按钮                                            |
| `--accent` / `--accent-foreground`                                             | 轻微强调                                                      |
| `--interactive-hover-surface`                                                  | 列表、链接行等可点击区域的低对比度悬浮背景                    |
| `--muted` / `--muted-foreground`                                               | 弱化表面 / 次要文字                                           |
| `--border`                                                                     | 细边框、分隔线和卡片边框                                      |
| `--ring`                                                                       | 焦点环                                                        |
| `--surface-invert` / `--surface-invert-foreground` / `--surface-invert-border` | 在浅色和暗色模式中自动反转明暗的区块，例如页面末尾行动号召区  |
| `--brand-logo-blue` / `--brand-logo-pink`                                      | Logo 品牌色及经过确认的轻量界面强调；禁止替代功能状态色       |
| `--brand-canvas`                                                               | 浅色主题的中性暖白画布                                        |
| `--hero-ascii-tint`                                                            | 首页 ASCII 背景配方的低透明度柔光色；仅供该装饰层使用         |
| `--footer-dot-wordmark`                                                        | Footer 点阵品牌字标的低对比度圆点色；由前景色与背景色混合生成 |

## 功能状态色

`--destructive`、`--success`、`--warning`、`--info` 及其 `-foreground` 变量，是系统中唯一允许带明显色彩的变量。它们只能用于真实的状态含义，例如错误、表单验证和评分指示，不能作为装饰色使用。

## 使用示例

```css
/* 组件的 <style> 中 */
color: var(--foreground);
background: var(--card);
border: 1px solid var(--border);
```

```astro
<!-- Tailwind 工具类映射到同一组变量 -->
<div class="bg-card text-foreground border-border border">…</div>
<!-- 没有现成工具类时使用任意值语法 -->
<span class="text-[color:var(--muted-foreground)]">…</span>
```

## 使用规则

- 组件中禁止出现原始 hex、rgb 或 hsl 值。只有颜色变量文件、作为品牌输入来源的 `site.config.ts` 和 OG 图片生成代码可以保存直接颜色值。
- 暗黑模式不能手动反转颜色，语义变量会自动完成切换。
- `check:kpis` 会将硬编码的 Tailwind 色板工具类报告为错误。
