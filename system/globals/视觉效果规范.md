# 视觉效果规范

## 圆角

圆角变量包括 `--radius-xs` 到 `--radius-2xl`，以及 `--radius-full`。卡片和面板使用 `--radius-xl` 或 `--radius-2xl`；胶囊和徽章使用 `--radius-full`；输入框使用 `--radius-md` 或 `--radius-lg`。

## 阴影

在 `colors.css` 中定义了一套能够适应暗黑模式的阴影：

- `--shadow-sm`：轻微抬升，用于徽章和弱化卡片。
- `--shadow-md`：悬浮抬升和面板。
- `--shadow-lg`：重点表面，例如页面末尾的行动号召区。

阴影采用低透明度的中性黑色，暗黑模式下会适当加重。优先使用轻阴影和 `--border` 细边框形成结构，不使用厚重装饰阴影。

## 背景效果

- `.bg-grid`：通过径向遮罩逐渐淡出的浅色网格，是首屏的标志性背景。网格线来自 `--foreground`，因此会自动适应浅色和暗色模式。
- `.bg-glow`：柔和的单色聚光效果，只在允许动态效果时进行呼吸动画。

## 使用规则

- 同一种元素始终使用统一的圆角等级。
- 不要叠加多个厚重阴影，结构优先交给边框表现。
- 装饰图层必须设置 `aria-hidden` 和 `pointer-events: none`。
