# 视觉效果规范

## 圆角

圆角变量包括 `--radius-xs` 到 `--radius-2xl`，以及 `--radius-full`。卡片和面板使用 `--radius-xl` 或 `--radius-2xl`；胶囊和徽章使用 `--radius-full`；输入框使用 `--radius-md` 或 `--radius-lg`。

## 阴影

在 `colors.css` 中定义了一套能够适应暗黑模式的阴影：

- `--shadow-sm`：轻微抬升，用于徽章和弱化卡片。
- `--shadow-md`：悬浮抬升和面板。
- `--shadow-lg`：重点表面，例如页面末尾的行动号召区。

阴影采用低透明度的中性黑色，暗黑模式下会适当加重。优先使用轻阴影和 `--border` 细边框形成结构，不使用厚重装饰阴影。

## 背景效果

- `.bg-grid`：通过径向遮罩逐渐淡出的浅色网格，是首屏的标志性背景。网格线来自 `--foreground`，因此会自动适应浅色和暗色模式。
- `.bg-glow`：柔和的单色聚光效果，只在允许动态效果时进行呼吸动画。
- `.hero__ascii`：首页可选的 Canvas2D 字符画背景。启用时替换 `.bg-grid`，保留静态光晕；原图、字符层和整体边缘暗角共同工作，不在标题后方增加局部色块。图片完成解码后再生成字符，字符颜色由图片采样色与当前 `--foreground` 混合，并在主题切换时重新生成，确保浅色与暗色模式都有稳定对比度；图像近乎空白的区域也保留低透明度字符，不出现字符空洞。启用 `asciiEntrance="ripple"` 时，同一个 Canvas 从浏览器可视区域正中心绘制约 2.4 秒的俯视极坐标同心字符环，再把字符位置与方向插值回最终风景；圆环仅旋转受控数量的字符，完整字符风景预绘到离屏 Canvas，并从 1.15 秒起交叉显现到结束，以消除字符密度跳变并控制逐帧开销。首次开场期间隐藏并延迟加载首页非必要资源，完成后以最终字符风景承接加载，再以导航、问候语、标题、底部提示的顺序完成约 810 毫秒的分层揭幕。开场结束后仅局部更新字符，使风景中的字母和符号持续变化；离开视口或标签页隐藏时暂停，不持续重绘整个画布。首屏以下内容不参与揭幕；减少动态效果或初始化失败时直接显示最终静态页面。
- `.hero__transition`：全屏 ASCII Hero 的画布在桌面端向下延伸 `--space-3xl`，移动端延伸 `--space-2xl`，再通过渐变遮罩和限定区域背景模糊与后续内容形成羽化衔接。过渡层必须独立于会缩放的 `.hero__backdrop`，确保滚动放大时渐变末端仍贴合 Hero 底边；标题和页脚保持在原首屏位置。启用 `scrollZoom` 时只随滚动增强延伸区的模糊强度，减少动态效果模式下保持静态默认值。
- `.dot-wordmark`：页面 Footer 底部的 Canvas2D 粒子字标。圆点颜色使用 `--footer-dot-wordmark` 保持低对比度，字标采用自然宽高比并限制在 `--container-max`；首次进入视口时圆点从随机位置收敛成字，指针经过时在圆形影响区内逸散，并使用独立的低速回收缓动逐渐归位；减少动态效果模式下直接显示静态字标。
- `.ascii-404`：404 页面专用的单色 Canvas2D 字符数字。字符只读取 `--foreground`，首次显示时三个数字分别从左、上、右侧离散位置依次聚合，稳定后三个数字均保留亚像素级轻微漂移；减少动态效果、画布初始化失败或禁用脚本时直接显示静态 404，不影响页面说明与返回链接。

## 使用规则

- 同一种元素始终使用统一的圆角等级。
- 不要叠加多个厚重阴影，结构优先交给边框表现。
- 装饰图层必须设置 `aria-hidden` 和 `pointer-events: none`。
