# 间距与布局规范

间距变量定义在 `src/styles/tokens/spacing.css`。

## 间距等级

使用 `--spacing-*` 间距体系，以及映射到它的旧版 `--space-*` 别名：`xs` → 8px、`sm` → 12px、`md` → 16px、`lg` → 24px、`xl` → 32px、`2xl` → 48px、`3xl` → 80px。适合时优先使用 Tailwind 间距工具类。

## 内容容器

- `.container`：水平居中，最大宽度为 `var(--container-max)`，左右内边距为 `var(--container-px)`。
- 页面左右内边距随断点变化：手机 `px-4`、平板 `px-6`、桌面 `px-8`。
- 全站采用居中窄栏的纸张式版心：`--container-paper` 为 68rem，`--container-max` 映射到该变量。首页正文、文章列表、文章页、普通页面、页头与页脚保持同一条窄版心基线。
- 长文章正文继续控制在约 65–72 个英文字符内；Hero 可以保留满视口背景，但文字内容仍受共享版心约束。

## 区块节奏

- 各区块的垂直内边距应统一且充足。使用 `Section` 组件，或使用共享的 `.section-head` 标题、引导标签和简介组合。
- 相关元素使用间距等级进行分组，避免随意填写像素间距。

## 使用规则

- 禁止没有依据的数值，统一使用变量或工具类。
- 所有区块保持一致的左右内边距，使内容对齐到同一网格。
- 卡片内部至少使用 `--space-lg`，并保持统一的圆角。
